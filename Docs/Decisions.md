# Fantasy RTS/RPG — Decisions

> Статус: согласованные положения по состоянию на 03.11.2026. Идентификаторы `D-*` введены для репозитория; они **не восстанавливают нумерацию старых вопросов 1–28**. Не делать предположений об отсутствующих параметрах.

## Принятые решения

| ID | Тема | Решение |
|---|---|---|
| D-001 | Концепция | Фэнтезийная RTS/RPG, единый основной сюжет через несколько жизней, отдельные тактические сражения и глобальное путешествие |
| D-002 | Герой | Боевой юнит с обычными базовыми характеристиками, не сверхюнит |
| D-003 | Армия | Индивидуальные бойцы, поздний ориентир 50–100 |
| D-004 | Управление | Классическая RTS-мышь, отдельные бойцы и группы |
| D-005 | Классы | Класс бойца фиксирован, эффективность зависит от характеристик |
| D-006 | Рост | Солдаты развиваются автоматически от класса и практики; только герой распределяет параметры вручную |
| D-007 | Снаряжение | Шесть индивидуальных слотов, фиксированные параметры предметов; базовый спрайт не меняется |
| D-008 | Получение предметов | Торговля, добыча, простое изготовление NPC |
| D-009 | Армия и ресурсы | Нет регулярного содержания армии; есть стоимость найма и экипировки, численность ограничена Leadership |
| D-010 | Бой | Реальное время с тактической паузой, приказы можно отдавать во время паузы |
| D-011 | AI | Бойцы сами выбирают цели, способности и оборону; явные приказы игрока выше автономного поведения |
| D-012 | Способности | Рывки, отступления и отталкивание/отбрасывание разрешены |
| D-013 | Ближний бой | Динамические позиции вокруг цели (engagement slots), событийное перераспределение |
| D-014 | Поражение героя | При 0 HP герой теряет боеспособность; есть шанс спасения |
| D-015 | Ранения | Временные, серьёзные, редко постоянные |
| D-016 | Реинкарнация | Окончательная смерть → десятилетия спустя новая семья, детство пропускается |
| D-017 | Перенос между жизнями | Частичные воспоминания и основной сюжет сохраняются; характеристики, снаряжение и Leadership — нет |
| D-018 | Мир между жизнями | Упрощённая legacy-симуляция армии и владений, без автоматического наследования |
| D-019 | История | Следующая жизнь начинает ближайшую незавершённую веху; число жизней до завершения сюжета не ограничено |
| D-020 | RTS-миссии | Временные базы, 3–5 ветеранов, 1–2 локальных ресурса, рабочие и малый набор зданий |
| D-021 | Выжившие | Часть произведённых бойцов присоединяется к постоянной армии в рамках Leadership |
| D-022 | Контакты | Атака, отход или простые переговоры; без общей системы репутации и дипломатии |
| D-023 | Технологии | Unity 6 + URP, 3D-земля, 2D рисованные непиксельные спрайты, наклонная ортографическая камера |
| D-024 | Террейн | Блоки, дискретные высоты, уступы и рампы, одна поверхность на XZ, нет мостов/динамического изменения земли |
| D-025 | Процедурные карты | Генерация целиком при загрузке; seed, логика зон/маршрутов и связность до декоративного шума |
| D-026 | Навигация | Собственная, без Unity NavMesh; блок делится на 4×4 ячейки; восьмисвязный A*, запрет диагональных срезов, footprint |
| D-027 | Перемещение | Плавное в непрерывных координатах; общий коридор группы и индивидуальные пути/цели |
| D-028 | Столкновения | Союзники мягко обходят и уступают; враги могут блокировать, Move не продавливает заслон |
| D-029 | Приказы | Move обходит или останавливается; Attack-Move может атаковать блокирующего противника/здание |
| D-030 | Пересчёт | Событийный repath, recovery при застревании, бюджет вычислений |
| D-031 | Friendly fire | Союзные юниты не мешают дальним атакам, дружественный огонь полностью отсутствует |
| D-032 | Дальний бой | Проверка дальности/боевых правил, без физической коллизии траектории или линии огня; визуальный полёт косметический |
| D-033 | Архитектура | Минимальная достаточность и единственный владелец ответственности; изменения архитектуры после согласования |
| D-034 | Оптимизация | Не внедрять ECS, Jobs/Burst и сложную инфраструктуру без доказанной необходимости |
| D-035 | Тестирование | На ранних стадиях не создавать автотесты, fixtures или тестовую инфраструктуру |
| D-036 | Процесс | Отдельная ветка/PR, менеджерское ревью, проверка снизу вверх, merge после приёмки |

D-031 и D-032 фиксируют два последних утверждённых решения по стрельбе, но их локальные номера не соответствуют номерам прежних GDD-вопросов.

## Неутверждённые параметры — не считать контрактом

- **Camera/Input:** точная раскладка, скорость камеры, edge-scroll, диапазон зума и абсолютные границы.
- **Terrain:** размеры блока в Unity units, высота одного уровня, допустимые уклоны рамп и плоских площадок.
- **Navigation:** структура хранения динамической занятости, эвристика A*, локальное избегание и лимит repath.
- **Combat/RPG:** численные формулы урона, опыта, лечения, вероятности спасения, список категорий экипировки.
- **Art:** размеры атласов, точный набор исходных направлений и слоёв.
- **World/Persistence:** формат сохранений, подробности мировой legacy-симуляции и сюжетных вех.
- **RTS missions:** конкретные здания, ресурсы, цены и требования к победе.

**Процесс изменения решения:** описать альтернативу и затронутые системы → получить одобрение владельца → обновить Decisions/GDD → при изменении границ обновить Architecture.md → обновить Issue и критерии приёмки.
